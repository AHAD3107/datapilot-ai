# Contributing

1. Open or comment on an issue describing the bug or proposed change.
2. Keep changes focused and add tests for bug fixes or new behavior.
3. Run `python -m pytest -q` before submitting a pull request.
4. Never commit secrets, customer data, raw confidential CSVs, or generated private reports.
5. Document changes that affect split strategy, metrics, model versions, data handling, or decision labels.

This is an MVP. Please avoid claiming full model reliability, production-grade leakage detection, or WCAG-like certification of any statistical result.
