# Model and data notes

## TabPFN

DataPilot uses the official `tabpfn-client` SDK to call hosted TabPFN inference when `TABPFN_TOKEN` is configured. The client documentation states that this is a cloud-based service and dataset values are transmitted to its servers for processing. Do not upload confidential, personal, regulated, or otherwise sensitive data unless you have permission and have assessed the applicable policies.

The installed client uses the provider's configured default model unless changed intentionally. Before a contest submission, verify which TabPFN model version the current service resolves and check the model licence, API terms, pricing and eligibility rules for the intended use. The client library's software licence is not the same thing as the model weights' licence.

## Synthetic sample data

`data/sample_sales.csv` is deterministic synthetic data generated by `datapilot.sample_data.make_sample_sales`. It exists for demos and tests, not to support real retail claims. Never present its evaluation results as real customer or market performance.

## Model interpretation

A better holdout metric is evidence about this split, not proof of future performance. When rows are time-dependent, prefer chronological holdout; where multiple rows belong to the same customer/entity, group-aware splitting may be required. Review feature availability and potential leakage before interpreting a strong result.
